### GitHub Repository Description

**Hospital Emergency Room Interactive Dashboard 📊**

An interactive hospital emergency room dashboard created using **Excel** to analyze patient data and generate meaningful healthcare insights.
🔍 Key Feature
* Patient volume and monthly trend analysis
* Average patient waiting time
* Patient satisfaction score
* Admission vs. non-admission analysis
* Gender-wise patient analysis
* Age-group analysis
* Department referral analysis
* Year and month filters
* Interactive dashboard visualizations

 Skills & Tools
* **Microsoft Excel**
* **Power Query** – Data Cleaning & ETL
* **Power Pivot** – Data Modeling
* **DAX** – Measures & Calculations
* **Data Analysis**
* **Data Visualization**
* **Dashboard Development**
* **KPI Analysis**
  
The objective of this project is to transform raw **hospital emergency room data** into an interactive dashboard that helps understand patient trends, waiting times, admissions, satisfaction, demographics, and department referrals.
